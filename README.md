# AdaptFit

An LLM-powered workout coach that adapts your program based on whether
you *actually* follow it — not just a plan generator.

Most fitness apps generate a plan and stop. AdaptFit closes the loop:
it logs what you actually do, computes adherence signals (completion
rate, missed streaks, volume trends), and hands those signals to an
LLM whose only job is to react to them — simplifying a muscle group
you keep skipping, holding steady or progressing one you're hitting
consistently.

## Why this exists

I built this to fix a real problem in my own training — consistency,
not knowledge. It's also a deliberately different kind of AI project
from a typical RAG demo: instead of retrieval quality, the interesting
part here is a **feedback loop where model output is conditioned on
structured behavioral data**, closer to how a real personalization or
recommendation system works.

## Architecture

```
                    ┌─────────────┐
   workout logs --> │   SQLite    │
                    │  db.py      │
                    └──────┬──────┘
                           │
                           v
                  ┌────────────────┐
                  │ adherence.py   │   completion rate,
                  │ (plain Python) │   missed streaks,
                  └────────┬───────┘   volume trends
                           │
                           v
                  ┌────────────────┐
                  │ llm_coach.py   │   Groq (Llama 3.3 70B)
                  │                │   reacts to the report,
                  └────────┬───────┘   generates next week's plan
                           │
                           v
                  ┌────────────────┐
                  │    app.py      │   Streamlit dashboard
                  │  (Streamlit)   │
                  └────────────────┘
```

Each layer only depends on the one below it — `adherence.py` never
calls the LLM, and `app.py` never touches raw logs directly. That
separation is deliberate: the deterministic adherence math is testable
and auditable on its own, and the LLM only ever sees a clean summary,
not raw rows — which keeps its output grounded instead of hallucinating
patterns from noisy data.

## Features

- **Adherence tracking** — completion rate by muscle group and day of
  week, computed from real logged sessions
- **Missed-streak detection** — flags a muscle group once it's been
  fully skipped for 2+ consecutive weeks
- **Volume trend tracking** — estimated training volume (sets x reps x
  weight) per muscle group over time
- **LLM-adjusted programming** — each week's plan is generated by
  Llama 3.3 70B (via Groq's free API) with a rationale explaining what
  changed and why, grounded in the actual adherence numbers
- **Dashboard** — Streamlit + Plotly visualization of everything above

## Tech stack

Python, SQLite, pandas, Groq API (Llama 3.3 70B, free tier),
Streamlit, Plotly

## Setup

```bash
git clone https://github.com/<your-username>/adaptfit.git
cd adaptfit
pip install -r requirements.txt
```

Get a free Groq API key at [console.groq.com](https://console.groq.com)
(no credit card required), then:

```bash
cp .env.example .env
# paste your key into .env
```

## Usage

```bash
cd src

# 1. Create the database
python db.py

# 2. Seed a week of example data (or start logging real workouts)
python seed.py

# 3. See the adherence numbers
python adherence.py

# 4. Generate next week's plan with the LLM
python llm_coach.py

# 5. Launch the dashboard
streamlit run app.py
```

## Project structure

```
adaptfit/
├── src/
│   ├── db.py           # SQLite schema + connection helper
│   ├── seed.py          # seeds example week of plan + logs
│   ├── adherence.py     # completion rate, streaks, volume — no LLM
│   ├── llm_coach.py      # Groq API call, generates + saves next week's plan
│   ├── app.py            # Streamlit dashboard
│   └── check_db.py       # sanity-check script for row counts
├── data/                 # SQLite db lives here (gitignored)
├── .env.example          # template for your Groq API key
├── requirements.txt
└── README.md
```
